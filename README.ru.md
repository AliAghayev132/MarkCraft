# MarkCraft

[English](README.md) · [Azərbaycanca](README.az.md) · **Русский**

Профессиональный настольный редактор Markdown на Electron, React и TypeScript.

MarkCraft одинаково хорош для двоих: для **автора**, которому нужна спокойная
рабочая поверхность и который не хочет думать о синтаксисе, и для
**разработчика**, которому нужны настоящий редактор исходника, дерево файлов,
поиск по проекту и управление всем с клавиатуры.

## Возможности

| Область | Что это даёт |
|---|---|
| **Три поверхности редактирования** | WYSIWYG-редактор, полноценный редактор исходного Markdown и живой предпросмотр — как три вида *одного* документа, а не три его копии. |
| **Раздельный вид** | Исходник и предпросмотр рядом; синхронизация прокрутки построена на реальном сопоставлении строк, а не на процентах. |
| **Свой файловый навигатор** | Ленивое виртуализированное дерево: полный CRUD, множественное выделение, перетаскивание, фильтр и сортировка. Открытие репозитория из 50 000 файлов стоит ровно столько папок, сколько вы раскрыли. |
| **Вкладки** | С изменяемым порядком, индикатором несохранённого, «закрыть остальные»/«закрыть все» и возвратом закрытой. |
| **Поиск по проекту** | Поиск и замена по всей папке — с глобами, регулярными выражениями, целым словом и учётом регистра. |
| **Палитра команд** | `Ctrl/Cmd + Shift + P`. Все действия приложения — один список с поиском. |
| **Переназначаемые сочетания** | Сочетание любой команды меняется в Настройках → Клавиатура. |
| **Восстановление после сбоя** | Несохранённая работа непрерывно пишется в журнал и предлагается обратно при следующем запуске — включая безымянные документы. |
| **Защита от конфликтов** | Внешние изменения обнаруживаются, и сохранение никогда молча не затирает файл, изменившийся под вами. |
| **Экспорт и печать** | Markdown, самодостаточный HTML и постраничный PDF; печатается документ, а не редактор. |
| **Темы** | Светлая, тёмная и системная, семь акцентных цветов, шесть именованных палитр (Nord, Solarized, Gruvbox, Rosé Pine, Sepia, высокий контраст) и переопределение отдельных цветов встроенной пипеткой. |
| **Три языка** | Английский, азербайджанский и русский — а четвёртый добавляется JSON-файлом в папку данных приложения, пересборка не нужна. |
| **Markdown-навигатор** | Дерево показывает только файлы, которые редактор умеет открывать. Один переключатель в Настройках → Файлы возвращает остальное. |
| **Свои значки и цвета** | Задайте файлу, папке или целому типу файлов свой значок и цвет — из встроенного набора или из ваших SVG. |
| **Масштаб интерфейса** | `Ctrl/Cmd +` и `Ctrl/Cmd -` масштабируют боковую панель и настройки независимо от текста редактора. |
| **Открывается как документ** | Двойной щелчок по `.md` открывает чистый режим чтения — свёрстанный документ и кнопка «Редактировать», а не редактор с панелями. |
| **Структура** | Живое оглавление в боковой панели — `Ctrl/Cmd + Shift + U`. Разбирается из Markdown, поэтому работает в любом режиме. |
| **Цели по словам** | Задайте цель для документа; строка состояния следит за ней. |
| **Отправить документ почтой** | Открывает черновик в вашем почтовом клиенте с вложенным `.md` — получателю ничего устанавливать не нужно. |
| **Формулы и диаграммы** | `$…$` отрисовывается через KaTeX; блок ```mermaid становится диаграммой, раскрашенной токенами самого приложения, — то есть следует вашей теме. Mermaid загружается только если диаграмма в документе действительно есть. |
| **Вики-ссылки** | `[[Другая заметка]]` ведёт на `Другая заметка.md` и разрешается как обычная относительная ссылка. |
| **Шаблоны** | `Ctrl/Cmd + Alt + N` начинает документ с готовой формы — заметки о встрече, статья, список дел — на вашем языке, а не английская рыба. |
| **Редактирование таблиц** | В WYSIWYG-виде элементы управления появляются, когда курсор внутри таблицы; вертикальные черты Markdown — единственное место, где кнопка лучше синтаксиса. |
| **Свой ИИ** | По желанию, по умолчанию выключен. Подключите OpenRouter, OpenAI, Anthropic, Gemini, Groq, DeepSeek, Mistral, Together, xAI, Fireworks — или локальные Ollama / LM Studio — и получите «Причесать текст», «Добавить деталей», «Кратко изложить» и свободные инструкции для выделения. Ключи шифруются под вашей учётной записью ОС и никогда не попадают в `settings.json`. |
| **Поиск по настройкам** | Начните печатать в настройках — найдётся любой параметр на всех страницах; выбор результата открывает нужную страницу с подсвеченным элементом. |
| **Режим презентации** | `F5` превращает документ в слайды по `---`. Слайды рендерятся конвейером предпросмотра, поэтому таблица выглядит одинаково. |
| **Меню блоков по `/`** | Слэш в начале строки открывает четырнадцать блоков — заголовки, списки, выноски, таблицы, эмодзи. Не появляется внутри путей и URL, совпадает и с английским названием, и с вашим языком. |
| **Инструменты разработчика** | `Ctrl/Cmd + Alt + T`. JSON, JSON↔YAML, Base64, URL, JWT, метки времени, тестер регулярных выражений и UUID — всё офлайн, потому что вставляют сюда обычно токен или данные клиента. |
| **Ссылки и граф** | `Ctrl/Cmd + Alt + L` показывает, как документы ссылаются друг на друга, перечисляет обратные ссылки и сообщает о каждой битой ссылке с файлом и строкой. |
| **Просмотр как сайт** | `Ctrl/Cmd + Alt + W` показывает документ шириной 390, 768 и 1280 пикселей — настоящая рамка, поэтому текст переносится ровно так, как увидит читатель. |
| **Обрезка и сжатие изображений** | Локальные изображения обрезаются и сжимаются до попадания в документ, итоговый размер виден сразу. WebP, поэтому прозрачность сохраняется. |
| **Выноски** | `> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]` — и в редакторе, и в экспорте. |
| **Выбор эмодзи** | `Ctrl/Cmd + Alt + M`, панель инструментов или `/emoji`. С поиском, часто используемые сверху. |
| **Линтер Markdown** | Девять правил, ловящих то, что действительно отображается неверно — заголовок без пробела после решётки, незакрытый блок, изображение без alt-текста — плюс битые якоря и дубли заголовков. |
| **Настраиваемая панель** | Выберите, какие инструменты показывать и в каком порядке. |
| **Восемь форматов экспорта** | Markdown, простой текст, rich text (.rtf), Word (.docx), автономный HTML, постраничный PDF, PNG и структурированный JSON. |
| **Режим книги** | `SUMMARY.md` со списком глав превращает папку в одно произведение — `Ctrl/Cmd + Alt + K`. Главы открываются по отдельности или объединяются в документ со сдвигом заголовков по глубине. Формат, который используют mdBook и GitBook. |
| **Режим учёбы** | Напишите «Термин :: значение» либо вопрос, строку только с `?` и ответ — и заметка становится карточкой. По одной за раз, с расписанием, которое переживает переписывание текста вокруг. |
| **Холст** | Бесконечная поверхность Markdown-карточек и связей, сохраняется как JSON Canvas — открытый формат Obsidian, открывается и там. |
| **HTTP-запрос** | Для API, о котором написан документ. Только `http://` и `https://` с проверкой на каждом редиректе, без кук и учётных данных, и только по нажатию. |
| **Выполнение блока кода** | Кнопка Run у любого блока на установленном языке. Вывод под самим блоком. Песочницы нет и она не обещается — код выполняется с вашими правами и никогда не запускается сам. |
| **Блокировка документа** | Отключает правку завершённого или чужого документа. Проверяется и при сохранении, поэтому автосохранение это учитывает. |
| **Серия письма** | Панель статистики считает дни, когда вы писали. Серия, закончившаяся вчера, сегодня ещё жива. В записи дата и число, не имя файла. |
| **Вставка как Markdown** | Преобразует форматированный текст из буфера конвейером предпросмотра — заголовки, списки и таблицы сохраняются, навигация и подвал страницы нет. |
| **Очистка форматирования** | Исправляет четыре проблемы с однозначным ответом — прижатый заголовок, табуляции, лишние пробелы, незакрытый блок — и не трогает спорные. |
| **Язык блока кода** | Задайте язык блока из палитры команд, в том числе ещё не закрытого. Список берётся из таблицы самой подсветки. |

Приоритет офлайна во всём. MarkCraft не делает сетевых запросов по своей
инициативе: ни телеметрии, ни проверки обновлений, ни шрифтов, подгружаемых во
время работы.

Единственное исключение — ИИ-ассистент, и это исключение вы делаете сами. Он
поставляется выключенным, без ключа и без адреса по умолчанию. Пока вы не
подключите провайдера и не включите его, ничто написанное вами не покидает
компьютер. А когда включите — приложение покажет, что именно собирается
отправить, до отправки.

## Начало работы

```bash
npm install
npm run dev
```

`npm run dev` запускает Vite с горячей перезагрузкой рендерера и перезапускает
главный процесс при изменениях.

### Другие скрипты

| Скрипт | Назначение |
|---|---|
| `npm run dev` | Разработка с HMR |
| `npm run build` | Проверка типов, затем сборка всех трёх бандлов в `out/` |
| `npm start` | Запустить собранное приложение |
| `npm test` | Прогнать набор тестов Vitest |
| `npm run lint` | ESLint, включая правила архитектурных границ |
| `npm run typecheck` | Проверка типов проектов main/preload и renderer |
| `npm run package` | Собрать распакованное приложение в `release/` |
| `npm run dist` | Собрать установщики для текущей платформы |

Требуется Node 20 или новее.

## Замечание о WYSIWYG-редакторе

Markdown не является канонической сериализацией дерева документа — `*em*` и
`_em_` разбираются одинаково, как и `# Заголовок` и заголовок, подчёркнутый по
правилам setext. Поэтому любой WYSIWYG-редактор, работающий через AST,
неизбежно перепишет текст, которого пользователь не касался.

MarkCraft решает это явно, а не надеется, что никто не заметит:

- Текст Markdown — единственный источник истины; редакторы это виды над ним.
- Ведёт только та поверхность, что в фокусе; остальные следуют за ней.
  Двусторонней привязки нет.
- WYSIWYG-редактор пересериализует при передаче управления, а не на каждое
  нажатие — поэтому тот, кто остаётся в исходнике, никогда не увидит
  переписанного форматирования.
- Стиль сериализации — видимая настройка, а документы с конструкциями, которые
  WYSIWYG-редактор упростил бы, сообщают об этом до начала правки.

Подробно это описано в [ARCHITECTURE.md](ARCHITECTURE.md#document-model).
